## 🔑 Points Clés

### Séparation Capabilities/Features/Screens
- **Capabilities** (15): Fonctionnalités permanentes
- **Features** (~75): Fonctions composées
- **Screens** (60+): Écrans UI

### Mode Optionnel Login/Signup
- L'utilisateur peut skip et continuer sans compte
- Les données restent locales (offline-first)
- Le cloud sync est optionnel (V1+)

### Modes de Mémorisation
1. **Word Mode** (standard): Tap-to-reveal mot par mot
2. **Read Mode**: Lecture concentrée
3. **Flashcard**: Recto/verso
4. **Focus Mode**: Full screen, zéro distraction
5. **Smart Mask**: Mots difficiles masqués (FSRS)
6. **Fill Missing**: Compléter les mots manquants
7. **Verification**: Écrire de mémoire

### Architecture Extensible
- Chaque feature a son propre dossier
- Les screens sont indépendants
- Easy to add new modes without modifying existing code
