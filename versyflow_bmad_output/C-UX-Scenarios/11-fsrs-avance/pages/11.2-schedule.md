## 5. States & Interactions

### States
- **Normal**: Planning affiché
- **TargetChanged**: Cible modifiée
- **Rescheduled**: Révision déplacée
- **SettingsOpen**: Modal paramètres

### Interactions
- Swipe item → options (repousser, supprimer)
- Tap item → révision immédiate
- Tap target → slider adjustment
- Tap settings → modal paramètres
- Pull to refresh → recalcul FSRS

### Smart Features
- **Auto-schedule**: Répartit automatiquement les révisions
- **Buffer**: Garde 20% de marge pour les imprévus
- **Optimization**: Sugère les meilleurs créneaux
