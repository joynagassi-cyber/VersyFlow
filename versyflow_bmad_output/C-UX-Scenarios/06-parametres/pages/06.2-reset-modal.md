## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Reset Confirmation Modal |
| Route | Modal overlay |
| User Goal | Confirmer la suppression destructive |

## 5. Interactions

### O-03 ConfirmInput
- **On input**: Check if text matches required word
- **On match**: Enable confirm button

### O-04 ConfirmButton
- **Disabled**: Until input matches
- **On tap**: Delete all data + navigate to Home + onboarding reset
- **On press**: Scale 0.96

### O-05 CancelButton
- **On tap**: Close modal, return to Settings

---

## 6. States

### Modal States
| State | Trigger | Description |
|-------|---------|-------------|
| Open | Settings tap | Modal visible |
| Typing | Input focus | Clavier ouvert |
| Match | Text matches | Bouton activé |
| Confirming | Button tap | Loading spinner |
| Deleted | Confirm | Toast + redirect |

### Component States
| Object | State | Description |
|--------|-------|-------------|
| O-04 Button | Disabled | Opacity 0.5 |
| O-04 Button | Enabled | Opacity 1, rouge |
| O-04 Button | Pressed | Scale 0.96 |

## 9. Design Notes

- **Safety**: Double confirmation obligatoire
- **Visual**: Rouge pour indiquer le danger
- **Friction**: Input requis empêche les accidents
- **Feedback**: Toast de confirmation après suppression
