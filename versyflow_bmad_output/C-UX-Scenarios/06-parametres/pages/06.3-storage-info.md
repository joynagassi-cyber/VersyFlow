- **Type**: Container + Button

### O-02: StorageChart
- **Type**: Visual

- **Description**: Donut chart ou barres montrant la répartition

### O-03: StorageRow (xN)
- **Type**: Row
- **Section**: Storage Breakdown

- **Type**: Button
- **Section**: Clear Cache

## 5. Interactions

### O-04 ClearCacheButton
- **On tap**: Confirm modal → clear cache → update display
- **Effect**: Réduit la taille du cache, pas les données utilisateur

## 8. Design Notes

- **Chart**: Donut visuel montrant la répartition
- **Rows**: Liste détaillée par catégorie
- **Clear cache**: Option sûr, ne supprime pas les données utilisateur
