## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Profile Screen |
| Route | `/profile` |
| User Goal | Gérer son profil utilisateur |
| Entry Point | Settings (tap "Profil") |
| Exit Point | Retour Settings |
| Device | Mobile |
| Mental State | Personalisation |

---

## 2. Layout Sections

### Section 1: Profile Header (Primary)
- **Purpose**: Avatar + nom + stats rapides
- **Priority**: Primary

### Section 2: Profile Info (Primary)
- **Purpose**: Modifier les infos personnelles
- **Priority**: Primary

### Section 3: Account Actions (Primary)
- **Purpose**: Connexion/déconnexion
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: ProfileHeader
- **Type**: Container
- **Section**: Profile Header
- **Description**: Avatar + nom + streak + versets mémorisés
- **Object ID**: `vs-profile-header`

### O-02: Avatar
- **Type**: Image/Circle
- **Section**: Profile Header
- **Description**: Avatar utilisateur (initials si pas d'image)
- **Object ID**: `vs-profile-avatar`

### O-03: NameInput
- **Type**: TextInput
- **Section**: Profile Info
- **Description**: Nom affiché
- **Object ID**: `vs-profile-name`

### O-04: ConnectButton
- **Type**: Button
- **Section**: Account Actions
- **Description**: "Se connecter" ou "Déconnexion"
- **Object ID**: `vs-profile-connect`

## 5. Interactions

### O-02 Avatar
- **On tap**: Changer l'avatar (gallery/camera)

### O-03 NameInput
- **On blur**: Sauvegarder le nom

### O-04 ConnectButton
- **On tap**: Navigate to Login/Signup ou déconnexion

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Guest | Not connected | Avatar initials, "Se connecter" |
| Connected | After login | Avatar + nom, "Déconnexion" |
| Editing | Tap name | Input actif |

## 8. Design Notes

- **Avatar**: Cercle avec initiales si pas d'image
- **Sync**: Les données de profil sont synchronisées si connecté
- **Privacy**: Pas de données sensibles stockées localement
