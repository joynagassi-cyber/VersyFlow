## 1. Page Basics

| Property | Value |

## 5. States & Interactions

### States
- **Default**: Toutes les stratégies visibles
- **Selected**: Carte sélectionnée highlighted
- **Loading**: Pendant transition
- **Disabled**: Si pas de verset sélectionné

### Interactions
- Tap stratégie → sélection + feedback haptique
- Tap Start → navigation vers session
- Swipe horizontal → scroll stratégies si overflow

### Accessibility
- Large touch targets (48px min)
- Clear visual distinction selected/unselected
- Screen reader labels
