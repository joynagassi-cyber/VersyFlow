## 5. Interactions

### O-03 LanguageCard
- **On tap**: Sélection mise à jour (bordure rose + checkmark)
- **On tap (already selected)**: Aucun effet
- **Haptic feedback**: Light pulse sur sélection

### O-04 ButtonPrimary
- **Default**: Disabled (opacity 0.5) tant qu'aucune langue sélectionnée
- **Enabled**: Actif quand une langue est sélectionnée
- **On tap**: Navigate to Translation Picker
- **RTL detection**: Si arabe → direction RTL appliquée

## 6. States

### Page States
| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Toutes cartes désélectionnées, bouton désactivé |
| Selected | Tap card | Carte mise en surbrillance |
| RTL | Arabic selected | Direction RTL appliquée |

### Component States
| Object | State | Description |
|--------|-------|-------------|
| O-03 Card | Default | Bordure grise, opacity 0.8 |
| O-03 Card | Selected | Bordure rose, checkmark visible |
| O-03 Card | Disabled | Opacity 0.5 (non disponible) |
| O-04 Button | Disabled | Opacity 0.5, pas de tap |
| O-04 Button | Enabled | Opacity 1, tap actif |

## 9. Design Notes

- **Grid layout**: 1 colonne sur mobile, 2 sur tablette
- **Card size**: Full width, height 56px
- **Selected state**: Border rose 2px + checkmark à droite
- **RTL**: Flip layout si arabe sélectionné
