# Page Specification — Home Screen

**Scenario**: 01 — Onboarding Complet
**Page**: 04
**Object ID**: `vs-home-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Home / Accueil |
| Route | `/` |
| User Goal | Accéder rapidement aux actions principales |
| Entry Point | Translation Picker (onboarding) ou tab Accueil |
| Exit Point | Explorer, Révisions, Progression, Paramètres |
| Device | Mobile |
| Mental State | Prêt à commencer, cherche l'action principale |

---

## 2. Layout Sections

### Section 1: Greeting (Primary)
- **Purpose**: Personnalisation et bienvenue
- **Priority**: Primary

### Section 2: Review Badge (Primary)
- **Purpose**: Notification des révisions en attente
- **Priority**: Primary

### Section 3: Quick Actions (Primary)
- **Purpose**: Accès rapide aux 2 actions principales
- **Priority**: Primary

### Section 4: Recent Verses (Secondary)
- **Purpose**: Rappel des versets récents
- **Priority**: Secondary

### Section 5: Tab Navigation (Primary)
- **Purpose**: Navigation principale
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: GreetingText
- **Type**: Text
- **Section**: Greeting
- **Description**: "Bienvenue, [nom]" ou "Bonjour"
- **Object ID**: `vs-home-greeting`

### O-02: ReviewBadge
- **Type**: Badge/Chip
- **Section**: Review Badge
- **Description**: "X versets à réviser"
- **Object ID**: `vs-home-review-badge`

### O-03: ActionCard (x2)
- **Type**: Card/Button
- **Section**: Quick Actions
- **Description**: "Mémoriser un verset" + "Réviser maintenant"
- **Object ID**: `vs-home-action-{type}`

### O-04: RecentVersesList
- **Type**: List
- **Section**: Recent Verses
- **Description**: 5 derniers versets mémorisés
- **Object ID**: `vs-home-recent`

### O-05: TabNavigation
- **Type**: Bottom Bar
- **Section**: Tab Navigation
- **Description**: 4 tabs — Accueil, Explorer, Progression, Paramètres
- **Object ID**: `vs-home-tabs`

## 5. Interactions

### O-02 ReviewBadge
- **On tap**: Navigate to Review Queue
- **Visibility**: Masqué si count = 0

### O-03 ActionCard
- **On tap "Mémoriser"**: Navigate to Explorer
- **On tap "Réviser"**: Navigate to Review Queue

### O-05 TabNavigation
- **On tap tab**: Navigate to section
- **Active state**: Icon + label rose
- **Badge**: Count sur tab Accueil si révisions en attente

---

## 6. States

### Page States
| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Greeting + actions |
| No reviews | count = 0 | Badge masqué |
| Has reviews | count > 0 | Badge visible |
| First time | No data | Empty state recent verses |

### Component States
| Object | State | Description |
|--------|-------|-------------|
| O-02 Badge | Hidden | count = 0 |
| O-02 Badge | Visible | count > 0 |
| O-04 List | Empty | Message "Commencez à mémoriser" |
| O-04 List | Loaded | 5 versets récents |
| O-05 Tabs | Active | Rose + indicator |
| O-05 Tabs | Inactive | Gris |

## 9. Design Notes

- **Quick actions**: 2 cartes grandes, faciles à tap
- **Badge**: Rouge si overdue, orange si scheduled
- **Tabs**: 4 tabs fixes en bas, toujours visibles
- **Personalization**: Utiliser le nom si disponible, sinon "Bonjour"
