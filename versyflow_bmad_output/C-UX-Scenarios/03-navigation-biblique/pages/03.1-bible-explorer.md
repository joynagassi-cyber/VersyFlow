# Page Specification — Bible Explorer (Full)

**Scenario**: 03 — Navigation Biblique
**Page**: 01-03
**Object ID**: `vs-bible-explorer`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Bible Explorer Screen |
| Route | `/explorer` |
| User Goal | Parcourir la Bible et trouver un verset |
| Entry Point | Tab Explorer ou Quick Action |
| Exit Point | Verse Detail, Chapter List, Verse List |
| Device | Mobile |
| Mental State | Recherche active, peut être pressé |

---

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Titre + recherche
- **Priority**: Primary

### Section 2: Sort Toggle (Secondary)
- **Purpose**: Trier par ordre canonique ou alphabet
- **Priority**: Secondary

### Section 3: Book List (Primary)
- **Purpose**: 66 livres groupés par testament
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + SearchBar
- **Section**: Header
- **Description**: "Explorer la Bible" + SearchBar
- **Object ID**: `vs-explorer-header`

### O-02: TabSegmented
- **Type**: Segmented Control
- **Section**: Sort Toggle
- **Description**: "Ordre" | "Alphabet"
- **Object ID**: `vs-explorer-sort`

### O-03: BookGroup (x2)
- **Type**: Section
- **Section**: Book List
- **Description**: Ancien Testament (39) + Nouveau Testament (27)
- **Object ID**: `vs-explorer-group-{testament}`

### O-04: BookItem (x66)
- **Type**: Card/Button
- **Section**: Book List
- **Description**: Nom du livre + nombre de chapitres
- **Object ID**: `vs-explorer-book-{code}`

---

## 4. Content & Languages

### O-02 TabSegmented
| Mode | FR | EN |
|------|----|----|
| Ordre | "Ordre" | "Order" |
| Alphabet | "Alphabet" | "Alphabet" |

---

## 5. Interactions

### O-01 SearchBar
- **On focus**: Clavier apparaît
- **On input**: Recherche par référence en temps réel
- **On submit**: Navigation vers Verse Detail

### O-02 TabSegmented
- **On tap**: Toggle entre Ordre/Alphabet
- **Default**: Ordre canonique

### O-04 BookItem
- **On tap**: Navigate to Chapter List
- **Sticky header**: Group headers restent visibles au scroll

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Liste des 66 livres |
| Sorting | Toggle tap | Tri alphabétique |
| Searching | Input | Résultats filtrés |
| No results | Filter empty | Message "Aucun livre trouvé" |

## 8. Design Notes

- **Sticky headers**: "Ancien Testament" et "Nouveau Testament" collants
- **Search**: Fuzzy matching, supports abréviations (Jn → Jean)
- **Sort**: Toggle entre ordre canonique et alphabétique
- **Offline**: Données chargées localement
