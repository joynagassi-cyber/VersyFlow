# Page Specification — History Screen

**Scenario**: 03 — Navigation Biblique
**Page**: 05
**Object ID**: `vs-history-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | History Screen |
| Route | `/history` |
| User Goal | Voir l'historique de ses révisions et mémorisations |
| Entry Point | Verse Detail (onglet historique) ou navigation directe |
| Exit Point | Verse Detail |
| Device | Mobile |
| Mental State | Analyse sa progression passée |

---

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Titre + retour
- **Priority**: Primary

### Section 2: Time Filter (Secondary)
- **Purpose**: Filtrer par période
- **Priority**: Secondary

### Section 3: History List (Primary)
- **Purpose**: Liste chronologique des activités
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: "Historique" + retour
- **Object ID**: `vs-history-header`

### O-02: TimeFilter
- **Type**: Segmented Control
- **Section**: Time Filter
- **Description**: "Aujourd'hui" | "7 jours" | "30 jours" | "Tout"
- **Object ID**: `vs-history-filter`

### O-03: HistoryItem (xN)
- **Type**: Card
- **Section**: History List
- **Description**: Événement avec date, type, verset
- **Object ID**: `vs-history-item-{id}`

## 5. Interactions

### O-02 TimeFilter
- **On tap**: Filter history by selected period

### O-03 HistoryItem
- **On tap**: Navigate to Verse Detail

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Liste chronologique |
| Filtered | Filter change | Versets filtrés |
| Empty | No history | Message "Aucun historique" |
| Loading | First render | Skeleton list |

## 8. Design Notes

- **Chronologique**: Du plus récent au plus ancien
- **Groupé**: Par jour (aujourd'hui, hier, cette semaine)
- **Types**: Icônes distinctes pour chaque type d'événement
- **Persistence**: Stocké localement dans MMKV
