# Page Specification — Chapter List (Enhanced)

**Scenario**: 03 — Navigation Biblique
**Page**: 02
**Object ID**: `vs-chapter-list-enhanced`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Chapter List Screen (Enhanced) |
| Route | `/explorer/books/:bookId/chapters` |
| User Goal | Sélectionner un chapitre |
| Entry Point | Book List (tap livre) |
| Exit Point | Verse List |
| Device | Mobile |
| Mental State | Cherche un chapitre spécifique |

---

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Retour + titre du livre
- **Priority**: Primary

### Section 2: Chapter Grid (Primary)
- **Purpose**: Grille 7 colonnes des chapitres
- **Priority**: Primary

### Section 3: Random Verse Button (Secondary)
- **Purpose**: Accès rapide à un verset aléatoire
- **Priority**: Secondary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: Retour + nom du livre
- **Object ID**: `vs-chap-exp-header`

### O-02: ChapterGrid
- **Type**: Grid (7 colonnes)
- **Section**: Chapter Grid
- **Description**: Chapitres avec numéros + compteurs
- **Object ID**: `vs-chap-exp-grid`

### O-03: ChapterTile
- **Type**: Card
- **Section**: Chapter Grid
- **Description**: Numéro + nombre de versets
- **Object ID**: `vs-chap-exp-tile-{num}`

### O-04: RandomVerseButton
- **Type**: Button
- **Section**: Random Verse
- **Description**: "🎲 Verset aléatoire"
- **Object ID**: `vs-chap-exp-random`

## 5. Interactions

### O-03 ChapterTile
- **On tap**: Navigate to Verse List
- **Visual indicator**: Badge vert si versets mémorisés dans ce chapitre

### O-04 RandomVerseButton
- **On tap**: Sélection aléatoire + navigate to Verse Detail

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Grille complète |
| Loading | First render | Skeleton grid |
| Has memorized | Data available | Indicators verts |

## 8. Design Notes

- **Grid**: 7 colonnes sur mobile, adaptatif sur tablette
- **Indicator**: Point vert bottom-right si versets mémorisés
- **Random**: Accessible depuis n'importe quel chapitre
