## 5. Interactions

### O-05 ActionButtons
- **On tap "Mémoriser"**: Navigate to Memorization Preview
- **On tap "Favori"**: Toggle favorite (haptic + animation cœur)
- **On tap "Copier"**: Copier texte + toast confirmation

### O-04 StatusInfo
- **Affichage**: Change selon le statut (Nouveau/En cours/Maîtrisé)
- **Prochain intervalle**: Affiché si verset déjà mémorisé

---

## 6. States

### Page States
| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Texte complet + actions |
| New | First time | Badge "Nouveau" + bouton "Mémoriser" actif |
| InProgress | Has record | Badge "En cours" + bouton "Continuer" |
| Mastered | Stable > 30j | Badge "Maîtrisé" + bouton "Réviser" |
| Favorited | Toggle | Cœur rempli |

### Component States
| Object | State | Description |
|--------|-------|-------------|
| O-03 Text | Default | Texte complet, line-height 1.7 |
| O-05 Button | Default | Opacity 1 |
| O-05 Button | Disabled | Opacity 0.5 (si verset déjà mémorisé → "Continuer") |
| O-05 Button | Pressed | Scale 0.96 |

## 9. Design Notes

- **Verse text**: Police serif pour le texte biblique (Georgia/Noto Serif)
- **Line height**: 1.7 pour la lisibilité
- **Actions**: 3 boutons horizontaux, Mémoriser en rose primary
- **RTL**: Texte aligné à droite si arabe
