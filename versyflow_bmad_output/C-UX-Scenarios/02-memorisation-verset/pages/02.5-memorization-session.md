| Property | Value |

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: Bouton quitter avec confirmation
- **Object ID**: `vs-mem-header`

### O-02: PhaseIndicator
- **Type**: Text + Progress bar
- **Section**: Phase Indicator
- **Description**: "Aperçu (10s)" ou "Mémorisation — tap pour révéler"
- **Object ID**: `vs-mem-phase`

### O-03: VerseDisplay
- **Type**: Text Container
- **Section**: Verse Display
- **Description**: Texte complet ou mots masqués
- **Object ID**: `vs-mem-verse`

### O-04: WordChip (xN mots)
- **Type**: Interactive Chip
- **Section**: Verse Display
- **Description**: Mot individuel — hidden ou revealed
- **Object ID**: `vs-mem-word-{index}`

### O-05: ProgressIndicator
- **Type**: Bar + Text
- **Section**: Progress
- **Description**: "X/Y mots révélés" + barre de progression
- **Object ID**: `vs-mem-progress`

### O-06: ValidationButtons (x2)
- **Type**: Buttons
- **Section**: Validation Buttons
- **Description**: "J'ai mémorisé" + "Besoin de plus de temps"
- **Object ID**: `vs-mem-btn-{action}`

### O-07: Timer
- **Type**: Text
- **Section**: (visible après 10s)
- **Description**: Compte à rebours ou temps écoulé
- **Object ID**: `vs-mem-timer`

## 5. Interactions

### O-01 HeaderBar
- **On tap**: Confirmation modal "Quitter sans mémoriser?"
- **On confirm**: Save progress + navigate back

### O-03 VerseDisplay
- **Preview phase**: Texte complet visible
- **Memorize phase**: Mots deviennent placeholders gris

### O-04 WordChip
- **Hidden state**: Placeholder gris (40x30px)
- **On tap**: Reveal word + pulse animation (300ms)
- **Revealed state**: Texte blanc sur fond rose

### O-06 ValidationButtons
- **On tap "J'ai mémorisé"**: FSRS note → Confirmation Screen
- **On tap "Besoin de plus de temps"**: Pause session + sauvegarder

## 9. Design Notes

- **Focus**: Pas de distractions — fond neutre, texte centré
- **Animations**: Pulse doux sur révélation de mot
- **Timer**: Discret, visible uniquement en phase preview
- **Pause**: Sauvegarde automatique tous les 5s
- **FSRS**: Calcul immédiat après validation
