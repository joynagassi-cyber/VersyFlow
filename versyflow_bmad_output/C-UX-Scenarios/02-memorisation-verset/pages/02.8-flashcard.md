## 5. Interactions

### O-01 Flashcard
- **On tap**: Flip card (recto → verso)
- **Animation**: Rotation 3D (flip)

### O-03 NavigationButtons
- **On tap "Précédent"**: Carte précédente
- **On tap "Suivant"**: Carte suivante

### O-04 FlipButton
- **On tap**: Flip card

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Recto | Default | Référence affichée |
| Verso | Tap/flip | Texte complet affiché |
| Last card | End of deck | Bouton suivant désactivé |
| First card | Start | Bouton précédent désactivé |

## 8. Design Notes

- **Flip animation**: Rotation 3D fluide (600ms)
- **Deck**: Plusieurs versets en mode flashcard
- **Self-rating**: Après avoir vu le verso, l'utilisateur peut s'évaluer
- **Shuffle**: Option pour mélanger l'ordre des cartes
