# Page Specification — Chapter List Screen

**Scenario**: 02 — Mémorisation d'un Verset
**Page**: 02
**Object ID**: `vs-chapter-list`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Chapter List Screen |
| Route | `/explorer/books/:bookId/chapters` |
| User Goal | Sélectionner un chapitre |
| Entry Point | Book List (tap livre) |
| Exit Point | Verse List |
| Device | Mobile |
| Mental State | Cherche un chapitre spécifique |

---

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Retour + titre du livre
- **Priority**: Primary

### Section 2: Chapter Grid (Primary)
- **Purpose**: Grille des chapitres avec nombres de versets
- **Priority**: Primary

### Section 3: Random Verse Button (Secondary)
- **Purpose**: Accès rapide à un verset aléatoire
- **Priority**: Secondary

### Section 4: Tab Navigation (Primary)
- **Purpose**: Navigation principale
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: Bouton retour + nom du livre
- **Object ID**: `vs-chap-header`

### O-02: ChapterGrid
- **Type**: Grid
- **Section**: Chapter Grid
- **Description**: Grille de chapitres (5 colonnes)
- **Object ID**: `vs-chap-grid`

### O-03: ChapterTile (xN)
- **Type**: Card/Button
- **Section**: Chapter Grid
- **Description**: Numéro de chapitre + nombre de versets
- **Object ID**: `vs-chap-tile-{num}`

### O-04: RandomVerseButton
- **Type**: Button
- **Section**: Random Verse Button
- **Description**: Bouton "Verset aléatoire"
- **Object ID**: `vs-chap-random`

### O-05: TabNavigation
- **Type**: Bottom Bar
- **Section**: Tab Navigation
- **Description**: 4 tabs
- **Object ID**: `vs-chap-tabs`

## 5. Interactions

### O-03 ChapterTile
- **On tap**: Navigate to Verse List
- **Visual indicator**: Badge vert si versets mémorisés dans ce chapitre

### O-04 RandomVerseButton
- **On tap**: Sélection aléatoire + navigate to Verse Detail

## 9. Design Notes

- **Grid**: 5 colonnes sur mobile, adaptatif sur tablette
- **Indicator**: Point vert si versets mémorisés présents
- **Random**: Accessible depuis n'importe quel chapitre
