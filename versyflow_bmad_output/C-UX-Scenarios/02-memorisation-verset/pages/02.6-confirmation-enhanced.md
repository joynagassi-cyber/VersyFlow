# Page Specification — Memorization Confirmation (Enhanced)

**Scenario**: 02 — Mémorisation d'un Verset
**Page**: 06
**Object ID**: `vs-memorization-confirm-enhanced`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Memorization Confirmation Screen (Enhanced) |
| Route | `/memorize/:verseId/confirm` |
| User Goal | Voir les résultats FSRS et décider de la suite |
| Entry Point | Memorization Session (validation) |
| Exit Point | Home ou nouveau verset |
| Device | Mobile |
| Mental State | Satisfaction, motivation |

## 2. Layout Sections

### Section 1: Success Animation (Primary)
- **Purpose**: Féliciter l'utilisateur
- **Priority**: Primary

### Section 2: Verse Summary (Primary)
- **Purpose**: Rappeler le verset mémorisé
- **Priority**: Primary

### Section 3: FSRS Result Card (Primary)
- **Purpose**: Afficher les métriques FSRS
- **Priority**: Primary

### Section 4: Action Row (Primary)
- **Purpose**: Choisir l'action suivante
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: SuccessIcon
- **Type**: Animation
- **Section**: Success Animation
- **Description**: Checkmark animé + confetti (milestones)
- **Object ID**: `vs-confirm-exp-icon`

### O-02: VerseSummary
- **Type**: Text Container
- **Section**: Verse Summary
- **Description**: Référence + traduction
- **Object ID**: `vs-confirm-exp-verse`

### O-03: FSRSResultCard
- **Type**: Card (white, shadow)
- **Section**: FSRS Result Card
- **Description**: Prochain intervalle, stabilité, difficulté
- **Object ID**: `vs-confirm-exp-fsrs`

### O-04: DoneButton
- **Type**: Button (secondary)
- **Section**: Action Row
- **Description**: "Terminé" → Home
- **Object ID**: `vs-confirm-exp-done`

### O-05: AddAnotherButton
- **Type**: Button (primary)
- **Section**: Action Row
- **Description**: "Ajouter un autre" → Explorer
- **Object ID**: `vs-confirm-exp-add`

## 8. Design Notes

- **Celebration**: Animation checkmark + son doux
- **FSRS card**: White card with shadow, 3 métriques claires
- **Milestones**: Confetti à 7, 30, 100 jours de streak
- **Quick action**: "Ajouter un autre" pour flux continu
