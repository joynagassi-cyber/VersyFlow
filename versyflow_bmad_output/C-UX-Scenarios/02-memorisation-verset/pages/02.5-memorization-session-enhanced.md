## 5. Interactions

### O-01 SessionHeader
- **On tap close**: Confirmation modal "Quitter sans mémoriser?"
- **Timer**: Apparaît après 10s, compte à rebours

### O-02 WordRevealArea
- **Preview phase**: Texte complet visible
- **Memorize phase**: Mots deviennent placeholders

### O-04 RevealedWordRow
- **On tap word**: Reveal + pulse animation (300ms)
- **Stagger**: 50ms delay entre chaque mot

### O-06 ControlButtons
- **On tap "Besoin de plus de temps"**: Pause session, sauvegarder
- **On tap "J'ai mémorisé"**: FSRS note → Confirmation

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|

## 8. Design Notes

- **Focus mode**: Pas de distractions, fond neutre
- **Animations**: Pulse doux sur révélation, stagger 50ms
- **Timer**: Discret, visible uniquement en phase preview
- **Pause**: Sauvegarde automatique tous les 5s
- **FSRS**: Calcul immédiat après validation
- **Fade out**: Header fade out après 5s pour maximiser l'espace
