## 5. Interactions

### O-03 GapInput
- **On focus**: Clavier apparaît
- **On input**: Validation en temps réel (vert = correct, rouge = incorrect)
- **On blur**: Feedback visuel

### O-04 WordBank
- **On tap word**: Place le mot dans le prochain gap vide
- **Drag & drop**: (future) Glisser-déposer dans les gaps

### O-05 ValidateButton
- **On tap**: Vérifier toutes les réponses
- **Feedback**: Colorer les gaps corrects/incorrects

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Active | Entry | Gaps vides, mots dans la banque |
| Typing | Input focus | Clavier ouvert |
| Correct | Valid input | Gap vert |
| Incorrect | Invalid input | Gap rouge |
| Complete | All correct | Bouton validation activé |
| Verified | Tap validate | Feedback complet |

## 8. Design Notes

- **Mode tap**: Tap un mot de la banque → il va dans le prochain gap
- **Mode drag**: (future) Glisser-déposer
- **Feedback immédiat**: Vert/rouge pendant la saisie
- **Difficulté**: 20-40% des mots manquants selon la longueur du verset
- **Hints**: Option pour révéler un mot (coûte des points)
