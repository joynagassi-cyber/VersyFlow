# Page Specification — Comparison Result Screen

**Scenario**: 02 — Mémorisation d'un Verset
**Object ID**: `vs-comparison-result-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Comparison Result Screen |
| Route | `/verify/:verseId/result` |
| User Goal | Voir les différences entre sa saisie et le texte original |
| Entry Point | Verification Screen (après soumission) |
| Exit Point | Confirmation Screen |
| Device | Mobile |
| Mental State | Analyse de ses erreurs |

---

## 2. Layout Sections

### Section 1: Score Display (Primary)
- **Purpose**: Score de précision
- **Priority**: Primary

### Section 2: Side-by-side Comparison (Primary)
- **Purpose**: Texte original vs saisie utilisateur
- **Priority**: Primary

### Section 3: Error Analysis (Secondary)
- **Purpose**: Mots manquants/incorrects
- **Priority**: Secondary

### Section 4: Actions (Primary)
- **Purpose**: Reessayer ou continuer
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: ScoreDisplay
- **Type**: Large number + percentage
- **Section**: Score Display
- **Description**: Score de précision (ex: 85%)
- **Object ID**: `vs-comp-score`

### O-02: ComparisonView
- **Type**: Two-column layout
- **Section**: Side-by-side Comparison
- **Description**: Original (vert) vs Utilisateur (rouge/gris)
- **Object ID**: `vs-comp-view`

### O-03: ErrorList
- **Type**: List
- **Section**: Error Analysis
- **Description**: Liste des mots manquants/incorrects
- **Object ID**: `vs-comp-errors`

### O-04: ActionButtons (x2)
- **Type**: Buttons
- **Section**: Actions
- **Description**: "Réessayer" + "Continuer"
- **Object ID**: `vs-comp-btn-{action}`

## 5. Interactions

### O-04 ActionButtons
- **On tap "Réessayer"**: Retour Verification Screen
- **On tap "Continuer"**: Navigation Confirmation Screen

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Perfect | 100% match | Score vert + félicitations |
| Good | 80-99% | Score orange + encouragement |
| Needs work | <80% | Score rouge + encouragement |
| Error display | Submitted | Mots incorrects en rouge |

## 8. Design Notes

- **Color coding**: Vert = correct, Rouge = incorrect, Gris = manquant
- **Highlight**: Mise en évidence des différences
- **Word-by-word**: Comparaison mot par mot
- **Percentage**: Score global calculé automatiquement
