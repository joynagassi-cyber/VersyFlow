## 2. Layout Sections

### Section 1: Search Bar (Primary)
- **Purpose**: Recherche rapide par nom ou abrégé
- **Priority**: Primary

### Section 2: Book Groups (Primary)
- **Purpose**: Lister les 66 livres groupés par testament
- **Priority**: Primary

### Section 3: Tab Navigation (Primary)
- **Purpose**: Navigation principale
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: SearchBar
- **Type**: Input
- **Section**: Search Bar
- **Description**: Recherche par nom de livre ou abrégé
- **Object ID**: `vs-books-search`

### O-02: BookGroup (x2)
- **Type**: Section
- **Section**: Book Groups
- **Description**: Ancien Testament (39 livres) + Nouveau Testament (27 livres)
- **Object ID**: `vs-books-group-{testament}`

### O-03: BookItem (x66)
- **Type**: Card/Button
- **Section**: Book Groups
- **Description**: Carte livre avec nom + nombre de chapitres
- **Object ID**: `vs-books-item-{code}`

### O-04: TabNavigation
- **Type**: Bottom Bar
- **Section**: Tab Navigation
- **Description**: 4 tabs — Accueil, Explorer, Progression, Paramètres
- **Object ID**: `vs-books-tabs`

## 5. Interactions

### O-01 SearchBar
- **On focus**: Clavier apparaît
- **On input**: Filtrage en temps réel des livres
- **On clear**: Reset à la liste complète
- **On submit**: Naviguer vers le premier résultat

### O-03 BookItem
- **On tap**: Navigate to Chapter List
- **On long press**: Options rapides (verset aléatoire du livre)

## 9. Design Notes

- **Grouping**: 2 sections — Ancien (39) + Nouveau (27)
- **Sticky headers**: Group headers collants lors du scroll
- **Search**: Fuzzy matching sur les abréviations (Jn → Jean)
- **Offline**: Liste chargée en local, zéro network
