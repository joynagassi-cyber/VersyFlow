- **Priority**: Primary

- **Purpose**: Texte complet en grand
- **Priority**: Primary

### Section 3: Reading Controls (Secondary)
- **Purpose**: Taille texte, fond, mode focus
- **Priority**: Secondary

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header

### O-02: VerseDisplay
- **Type**: Text (large)

- **Section**: Reading Controls

- **Type**: Toggle
- **Section**: Reading Controls

## 5. Interactions

### O-04 FontSizeSlider
- **On drag**: Ajuster la taille du texte en temps réel
- **Presets**: Petit / Moyen / Grand / Très grand

### O-05 BackgroundToggle
- **On tap**: Cycler entre blanc / crème / sépia

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Texte en taille moyenne, fond blanc |
| Font changed | Slider drag | Texte redimensionné |
| Background changed | Toggle tap | Fond changé |
| Focus mode | Enable focus | Header et controls cachés |

---

## 7. Spacing & Typography

| ID | Between | Size |
|----|---------|------|
| `vs-read-v-space-xl` | Header → Verse | xl (32px) |
| `vs-read-h-space-lg` | Horizontal margin | lg (24px) |
| `vs-read-line-height` | Line spacing | 1.7 |

---

## 8. Design Notes

- **Typography**: Police serif (Georgia/Noto Serif) pour le texte biblique
- **Line height**: 1.7 pour la lisibilité
- **Fonds**: Blanc, crème (#FFF8F0), sépia (#F5E6D3)
- **Focus mode**: Cache tout sauf le texte
- **Taille**: De 16px à 32px selon préférence
