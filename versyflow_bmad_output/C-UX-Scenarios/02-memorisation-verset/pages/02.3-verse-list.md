## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Verse List Screen |
| Route | `/explorer/books/:bookId/chapters/:chapterNum/verses` |
| User Goal | Parcourir les versets d'un chapitre |
| Entry Point | Chapter List (tap chapitre) |

| Mental State | Lit les versets, cherche un passage spécifique |

### Section 1: Header (Primary)

- **Priority**: Secondary

- **Purpose**: Lister tous les versets du chapitre
- **Priority**: Primary

### Section 4: Random Verse Button (Secondary)
- **Purpose**: Accès rapide à un verset aléatoire
- **Priority**: Secondary

### Section 5: Tab Navigation (Primary)
- **Purpose**: Navigation principale
- **Priority**: Primary

## 5. Interactions

### O-02 SearchBar
- **On input**: Scroll automatique au verset recherché
- **On clear**: Retour à la liste complète

### O-03 VerseCard
- **On tap**: Navigate to Verse Detail
- **On long press**: Options (favori, copier, mémoriser)

### O-04 RandomVerseButton
- **On tap**: Sélection aléatoire + navigate to Verse Detail

## 9. Design Notes

- **Infinite scroll**: Chargement progressif si chapitre très long
- **Status colors**: Gris (new), Rose (in progress), Vert (mastered)
- **Text display**: Max 3 lignes avec ellipsis
- **RTL**: Texte aligné à droite si langue arabe
