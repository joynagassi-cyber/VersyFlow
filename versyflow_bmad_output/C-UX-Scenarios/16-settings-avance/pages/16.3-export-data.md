## 5. States & Interactions

### States
- **Ready**: Prêt à exporter
- **Exporting**: Animation progression
- **Complete**: Fichier généré
- **Error**: Échec export

### Interactions
- Tap format → sélection
- Tap export → génération fichier
- Tap import → sélection fichier
- Share → partager via système

### Privacy
- Données 100% locales
- Pas de cloud sans consentement
- Suppression possible après export
