## 5. Interactions

### O-05 TapToRevealZone
- **On tap**: Révéler tout le verset
- **Auto-reveal**: Après 30s sans interaction

### O-06 ResponseButtons
- **On tap**: FSRS update → next verse
- **Animation**: Scale + color flash + transition

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Presenting | Entry | Verset partiellement caché |
| Revealed | Tap/Auto | Verset révélé, boutons visibles |
| Responding | Button tap | Feedback visuel |
| Transition | After response | Animation vers suivant |
| Complete | Last verse | Navigation session complete |

## 8. Design Notes

- **Full-screen**: Mode focus, pas de distractions
- **Progress bar**: Fine bar rose en haut de l'écran
- **Card**: Grande carte centrée avec ombre
- **Response buttons**: 3 boutons empilés verticalement
- **FSRS feedback**: Apparaît 2s après réponse puis disparaît
