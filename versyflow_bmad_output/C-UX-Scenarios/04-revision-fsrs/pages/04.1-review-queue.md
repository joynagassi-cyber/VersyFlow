## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Review Queue Screen |
| Route | `/reviews` |
| User Goal | Voir les révisions en attente et commencer |
| Entry Point | Home (badge tap) ou tab navigation |
| Exit Point | Review Session |
| Device | Mobile |
| Mental State | Prêt à réviser, motivé |

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Titre + navigation retour
- **Priority**: Primary

### Section 2: Queue Summary (Primary)
- **Purpose**: Résumé des révisions (compteurs)
- **Priority**: Primary

### Section 3: Queue List (Primary)
- **Purpose**: Lister les versets par urgence
- **Priority**: Primary

### Section 4: Start Button (Primary)
- **Purpose**: Lancer la session de révision
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: "Révisions" + retour
- **Object ID**: `vs-rev-queue-header`

### O-02: SummaryCards (x3)
- **Type**: Cards
- **Section**: Queue Summary
- **Description**: Aujourd'hui / Cette semaine / Total
- **Object ID**: `vs-rev-queue-summary-{type}`

### O-03: ReviewItemCard (xN)
- **Type**: Card
- **Section**: Queue List
- **Description**: Verset + urgence + prochain intervalle
- **Object ID**: `vs-rev-queue-item-{id}`

### O-04: StartButton
- **Type**: Button
- **Section**: Start Button
- **Description**: "Commencer la révision"
- **Object ID**: `vs-rev-queue-start`

## 9. Design Notes

- **Urgence colors**: Rouge (overdue) → Orange (today) → Vert (upcoming)
- **Tri**: FSRS ordonne par priorité (overdue > scheduled > upcoming)
- **Empty state**: Message motivant + CTA vers Explorer
