# Page Specification — Review Summary Screen

**Scenario**: 04 — Révision FSRS
**Object ID**: `vs-review-summary-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Review Summary Screen |
| Route | `/reviews/summary` |
| User Goal | Voir le récap détaillé de la session de révision |
| Entry Point | Review Session (après tous les versets) |
| Exit Point | Home |
| Device | Mobile |
| Mental State | Satisfaction, analyse |

---

## 2. Layout Sections

### Section 1: Celebration (Primary)
- **Purpose**: Féliciter l'utilisateur
- **Priority**: Primary

### Section 2: Session Stats (Primary)
- **Purpose**: Statistiques détaillées de la session
- **Priority**: Primary

### Section 3: Performance Breakdown (Primary)
- **Purpose**: Analyse des performances
- **Priority**: Primary

### Section 4: Next Reviews Preview (Secondary)
- **Purpose**: Aperçu des prochaines révisions
- **Priority**: Secondary

### Section 5: Finish Button (Primary)
- **Purpose**: Retour à l'accueil
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: CelebrationIcon
- **Type**: Animation
- **Section**: Celebration
- **Description**: 🎉 + confetti
- **Object ID**: `vs-rev-sum-icon`

### O-02: StatsGrid (x4)
- **Type**: Cards
- **Section**: Session Stats
- **Description**: Corrects, Hard, Again, Temps total
- **Object ID**: `vs-rev-sum-stat-{type}`

### O-03: PerformanceChart
- **Type**: Chart
- **Section**: Performance Breakdown
- **Description**: Graphique des réponses par verset
- **Object ID**: `vs-rev-sum-perf`

### O-04: NextPreview
- **Type**: Text
- **Section**: Next Reviews Preview
- **Description**: "5 versets demain"
- **Object ID**: `vs-rev-sum-next`

### O-05: FinishButton
- **Type**: Button
- **Section**: Finish Button
- **Description**: "Terminer"
- **Object ID**: `vs-rev-sum-finish`

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Complete | Entry | Stats affichées |
| Milestone | 7/30/100 révisions | Confetti extra |
| Poor performance | <50% correct | Message encourageant |

## 8. Design Notes

- **Motivation**: Stats positives même si performance moyenne
- **Progress**: Montrer l'amélioration par rapport à la semaine précédente
- **Encouragement**: Message adapté selon les performances
