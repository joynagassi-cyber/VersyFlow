## 2. Layout Sections

- **Priority**: Primary

- **Priority**: Primary

### Section 3: Detailed Charts (Primary)
- **Purpose**: Graphiques détaillés
- **Priority**: Primary

### Section 4: Insights (Secondary)
- **Purpose**: Conseils personnalisés
- **Priority**: Secondary

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container
- **Section**: Header
- **Description**: "Statistiques" + sélecteur période
- **Object ID**: `vs-stat-header`

### O-02: OverviewGrid (x4)
- **Type**: Cards
- **Section**: Overview Stats
- **Description**: 4 métriques clés détaillées
- **Object ID**: `vs-stat-overview-{type}`

### O-03: TrendChart
- **Type**: Chart
- **Section**: Detailed Charts
- **Description**: Courbe de progression sur la période
- **Object ID**: `vs-stat-trend`

### O-04: CategoryBreakdown
- **Type**: Chart
- **Section**: Detailed Charts
- **Description**: Répartition par type de verset
- **Object ID**: `vs-stat-category`

### O-05: InsightsCard
- **Type**: Card
- **Section**: Insights
- **Description**: Conseils basés sur les données
- **Object ID**: `vs-stat-insights`

## 5. Interactions

### O-01 HeaderBar
- **On tap période**: Changer la période (7j, 30j, 90j, tout)

### O-03 TrendChart
- **On tap point**: Voir le détail du jour

### O-04 CategoryBreakdown
- **On tap segment**: Filtrer par catégorie

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Stats affichées |
| Loading | First render | Skeleton charts |
| Empty | No data | Message "Commencez à mémoriser" |
| Period changed | Period tap | Charts mis à jour |

## 8. Design Notes

- **Périodes**: 7 jours, 30 jours, 90 jours, tout
- **Charts**: Line chart pour la tendance, bar chart pour les catégories
- **Insights**: Algorithmes simples basés sur les données
- **Export**: Bouton pour exporter en CSV (V1+)
