## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Titre catégorie + retour
- **Priority**: Primary

### Section 2: Filter Bar (Secondary)
- **Purpose**: Tri par date, référence, statut
- **Priority**: Secondary

### Section 3: Verse List (Primary)
- **Purpose**: Liste des versets
- **Priority**: Primary

---

## 3. Components & Objects

### O-01: HeaderBar
- **Type**: Container + Button
- **Section**: Header
- **Description**: Retour + titre catégorie
- **Object ID**: `vs-dvl-header`

### O-02: FilterBar
- **Type**: Horizontal scroll
- **Section**: Filter Bar
- **Description**: Filtres: Tous, Récents, À renforcer
- **Object ID**: `vs-dvl-filter`

### O-03: VerseCard (xN)
- **Type**: Card
- **Section**: Verse List
- **Description**: Verset + référence + statut + days
- **Object ID**: `vs-dvl-verse-{id}`

## 5. Interactions

### O-02 FilterBar
- **On tap**: Apply filter, refresh list

### O-03 VerseCard
- **On tap**: Navigate to Verse Detail
- **On swipe**: Options (favori, réviser maintenant)

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Liste complète |
| Filtered | Filter tap | Versets filtrés |
| Empty | No results | Message "Aucun verset" |
