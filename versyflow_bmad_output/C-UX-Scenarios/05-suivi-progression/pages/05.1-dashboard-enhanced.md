## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Stats affichées |
| Loading | First render | Skeleton screens |
| Empty | No data | Message "Commencez à mémoriser" |

## 8. Design Notes

- **Stats grid**: 2x2, cards égales avec icônes
- **Chart**: Barres roses, jours de la semaine en dessous
- **Colors**: Vert (maîtrisé), Rose (en cours), Orange (à réviser)
- **Animations**: Count-up sur les chiffres, confetti aux milestones
- **Achievements**: Section future, empty state avec message "À venir"
