# Page Specification — Signup Screen (Optional)

**Scenario**: 00 — Authentification
**Page**: 02
**Object ID**: `vs-signup-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Signup Screen |
| Route | `/signup` |
| User Goal | Créer un compte pour synchroniser |
| Entry Point | Login Screen (tap signup link) |
| Exit Point | Home (connecté) ou LoginScreen |
| Device | Mobile |
| Mental State | Decide à s'inscrire ou non |

---

## 2. Layout Sections

### Section 1: Header (Primary)
- **Purpose**: Titre + retour
- **Priority**: Primary

### Section 2: Form (Primary)
- **Purpose**: Email + mot de passe + confirmation
- **Priority**: Primary

### Section 3: Actions (Primary)
- **Purpose**: Créer le compte
- **Priority**: Primary

### Section 4: Login Link (Secondary)
- **Purpose**: Retour à la connexion
- **Priority**: Secondary

## 5. Interactions

### O-05 SignupButton
- **On tap**: Validation → création compte → connexion auto → Home
- **Loading**: Spinner sur le bouton
- **Error**: Toast avec message

### O-06 LoginLink
- **On tap**: Navigate to LoginScreen

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Formulaire vide |
| Filled | Inputs filled | Bouton activé |
| Loading | Tap signup | Spinner |
| Error | Invalid data | Toast erreur |
| Success | Account created | Redirect Home |
| Exists | Email already exists | Message "Cet email est déjà utilisé" |

---

## 7. Validation

| Field | Rule | Error |
|-------|------|-------|
| Email | Required, valid email | "Veuillez entrer un email valide" |
| Password | Required, min 8 chars, 1 uppercase, 1 number | "Le mot de passe doit contenir au moins 8 caractères" |
| Confirm Password | Must match password | "Les mots de passe ne correspondent pas" |

## 9. Design Notes

- **Optionnel**: L'utilisateur peut skip et continuer sans compte
- **Sécurité**: Validation mot de passe côté client
- **Confirmation**: Double saisie du mot de passe
- **Existing account**: Message clair si l'email existe déjà
