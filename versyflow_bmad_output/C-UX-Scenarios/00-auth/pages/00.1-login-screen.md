## 5. Interactions

### O-04 LoginButton
- **On tap**: Validation formulaire → connexion → Home
- **Loading**: Spinner sur le bouton
- **Error**: Toast avec message d'erreur

### O-05 SignupLink
- **On tap**: Navigate to SignupScreen

### O-06 SkipButton
- **On tap**: Navigate to Home (without auth)

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Default | Load | Formulaire vide |
| Filled | Input | Bouton activé |
| Loading | Tap login | Spinner sur bouton |
| Error | Invalid creds | Toast erreur |
| Success | Valid login | Redirect Home |

---

## 7. Validation

| Field | Rule | Error |
|-------|------|-------|
| Email | Required, valid email | "Veuillez entrer un email valide" |
| Password | Required, min 8 chars | "Le mot de passe doit contenir au moins 8 caractères" |

## 9. Design Notes

- **Optionnel**: L'utilisateur peut skip et continuer sans compte
- **Sécurité**: Mot de passe masqué, validation côté client
- **Cloud sync**: Optionnel, les données restent locales si pas connecté
- **Remember**: Option "Se souvenir de moi" (future)
