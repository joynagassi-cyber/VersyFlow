## 5. States & Interactions

### States
- **Loading**: Skeleton chart
- **Normal**: Courbe affichée
- **NoData**: Message incitatif
- **Comparing**: Deux courbes (vs moyenne)

### Interactions
- Pinch/zoom sur le graphique
- Tap point → tooltip avec date/valeur
- Swipe horizontal → changer période
- Tap stat → détail modal

### Data Sources
- FSRS stability values
- Review history
- Calculation algorithm
