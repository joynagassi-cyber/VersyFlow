## 4. Content & Languages

### O-01 DifficultyOverview
| Stat | Description |
|------|-------------|
| Avg FSRS Difficulty | Difficulté moyenne FSRS |
| Hardest Word | Mot le plus difficile |
| Improvement | % amélioration |

### O-02 WordHeatmap
- **X-axis**: Sessions (derniers 10)
- **Y-axis**: Mots du verset
- **Colors**:
  - Vert: Facile (réussi du premier coup)
  - Jaune: Moyen (quelques erreurs)
  - Rouge: Difficile (beaucoup d'erreurs)

### O-03 DifficultVerseList
- **Format**:
  ```
  Psaume 23:1
  Difficulté: 8.2/10
  Mots difficiles: "Éternel", "berger"
  [Réviser]
  ```

## 5. States & Interactions

### States
- **Normal**: Données affichées
- **NoData**: Pas assez de données
- **Improving**: Tendances positives

### Interactions
- Tap word cell → voir historique
- Tap verse → révision ciblée
- Swipe heatmap → changer période

### Algorithm
- **Word difficulty**: Basé sur les échecs de rappel
- **Verse difficulty**: Moyenne pondérée des mots
- **Trend**: Comparaison semaine vs semaine précédente
