# Page Specification — Boot Screen

**Scenario**: 00 — Premier Lancement
**Page**: 02
**Object ID**: `vs-boot-screen`
**Date**: 2026-08-03

---

## 1. Page Basics

| Property | Value |
|----------|-------|
| Title | Boot Screen |
| Route | `/boot` |
| User Goal | Chargement des données et initialisation |
| Entry Point | Splash Screen |
| Exit Point | WelcomeScreen (premier lancement) ou Home (retour) |
| Device | Mobile |
| Mental State | Attend le chargement |

---

## 2. Layout Sections

### Section 1: Loading Indicator (Primary)
- **Purpose**: Indicateur de chargement
- **Priority**: Primary

### Section 2: Status Text (Secondary)
- **Purpose**: Message de statut
- **Priority**: Secondary

---

## 3. Components & Objects

### O-01: LoadingSpinner
- **Type**: Animation
- **Section**: Loading Indicator
- **Description**: Spinner rose avec animation rotation
- **Object ID**: `vs-boot-spinner`

### O-02: StatusText
- **Type**: Text
- **Section**: Status Text
- **Description**: Messages de chargement progressifs
- **Object ID**: `vs-boot-status`

### O-03: ProgressBar (optionnel)
- **Type**: Bar
- **Section**: Loading Indicator
- **Description**: Barre de progression si chargement long
- **Object ID**: `vs-boot-progress`

## 5. Interactions

Aucune interaction utilisateur — écran automatique.

---

## 6. States

| State | Trigger | Description |
|-------|---------|-------------|
| Loading | Entry | Spinner + message "Initialisation..." |
| Loading Bible | Bible load | Message "Chargement de la Bible..." |
| Loading FSRS | WASM load | Message "Chargement FSRS..." |
| Ready | All loaded | Transition vers WelcomeScreen ou Home |
| Error | Load failure | Écran erreur avec retry |
| Fallback | WASM fail | Message "Mode fallback activé" |

---

| ID | Between | Size |
|----|---------|------|
| `vs-boot-v-space-xl` | Spinner → Status | xl (32px) |

---

## 8. Design Notes

- **Durée**: 1-3 secondes selon les données à charger
- **Messages**: Changent selon l'étape de chargement
- **Fallback**: Si WASM échoue, message discret + continuation
- **Transition**: Fade in vers l'écran suivant
